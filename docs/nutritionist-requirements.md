# 管理栄養士向け機能要件書

## 実際の使用シーン

1. 患者向けの食事メニュー作成
2. 一食あたりの食品ごとにグラム数を決定
3. 各食品の栄養成分を食品成分表から取得
4. 全食品の栄養素を積算
5. 総エネルギー、タンパク質、脂質、炭水化物を確認
6. 栄養バランスが目標値を満たしているか検証

## 現状の課題

- 手作業での積算（時間がかかる）
- Excel での管理（複雑・属人化）
- 食品成分表との照合が煩雑

## 要望機能（Phase 3 以降）

### 食事計画入力・自動積算機能

入力:
- 食品名 + グラム数

自動計算:
- エネルギー（kcal）
- タンパク質（g）
- 脂質（g）
- 炭水化物（g）

出力:
- 一食分の栄養積算結果
- 栄養バランス確認
- PDF/CSV エクスポート
